# Sandbox bench

The site behind Sandbox bench: 9 cloud sandbox providers for AI agents, timed on the same tests from one server in Florida.

It is a Next.js static export. The numbers live in `src/data/benchmark.json`, generated by the benchmark harness in the Sandbox SDK repo (`bun bench site-data`).

```sh
bun install
bun run dev      # local preview
bun run build    # static site in out/
```

Pushes to `main` deploy to production on Vercel.
